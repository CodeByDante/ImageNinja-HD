<h3 align="center">ImageNinja HD</h3>

<p align="center">
  <a href="https://github.com/CodeByDante/ImageNinja-HD/archive/refs/heads/main.zip">
    <img src="readme-button.svg" width="280" alt="DESCARGAR IMAGENINJA HD">
  </a>
</p>

**ImageNinja HD** es una extensión para encontrar y descargar imágenes de las páginas que visitas. Permite filtrar por formato, tamaño o palabras de la URL, revisar los resultados y seleccionar las imágenes que quieres guardar desde el navegador.
